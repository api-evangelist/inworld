# Inworld AI (inworld)

Inworld AI provides voice and conversational AI building blocks for games and interactive media. Public APIs cover Text-to-Speech, Speech-to-Text, a Realtime speech-to-speech API, and an LLM Router that fronts 220+ third-party models with unified billing.

## Pricing Snapshot
- On-Demand (Free): $0, ~40 min TTS included
- Creator: $25/mo, $25 credits, up to 100 custom voices
- Developer: $300/mo, $300 credits, up to 20% off rates
- Growth: $1,500/mo, $1,500 credits, up to 40% off rates
- Enterprise: custom (TTS as low as $10/1M characters)
- TTS-2 / 1.5 Max: $25–$35 per 1M chars
- TTS-1.5 Mini: $15–$25 per 1M chars
- STT: $0.35/hour
- LLM Router: provider cost
